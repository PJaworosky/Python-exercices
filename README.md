## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/python-exercises.git
```

### Navigate to the project folder

```bash
cd python-exercises
```

### Run any exercise

```bash
python filename.py
```

> Replace `filename.py` with the exercise you want to run.
